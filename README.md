# breathing-constants

つぶやきProcessing の一本のコードに直書きされた定数（`4, 9, 35, 40…`）を主役にした2つの実験。

## `lab.html` ── 係数実験台
直書き定数を全部つまみにして、「数字を1つ動かすと形はどこまで壊れるか」を触って確かめる台。
黒い縦線が元の値の位置。今の数字で書き直した p5.js コードもその場で出力する。

## `wallpaper.html` ── 二度と戻らない待受
同じ式の全定数を、互いに無理数比の滑らかな波でゆっくり漂わせたスマホ向けライブ待受。
準周期なので実質的に二度と同じ配置には戻らず、開くたびに違う。タップで一気に別の世界へ流れる。

## `lab-glsl.html` ── つぶやきGLSL 係数実験台
1行の #つぶやきGLSL（レイマーチで折り畳んだフラクタルを発光で描くやつ）版の実験台。
WebGL2 で本物のシェーダを走らせ、直書き定数を全部 uniform のつまみにして即時反映する。
今の数字で書き直した1行を twigl の geekest 形式で出力する。

どれも外部依存なしの単一 HTML。ブラウザで開くだけで動く。
