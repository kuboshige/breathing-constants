つぶやきGLSL / 係数実験台

この1行のシェーダ、定数を動かすと何が起きるか

レイマーチで折り畳んだフラクタルを発光で描く原典。直書きの 3, 6, 5, 6, 1e6… を全部つまみにした。黒い縦線が原典の値。

お使いのブラウザは WebGL2 に対応していないようです。
最新の Chrome / Safari / Firefox でお試しください。
| 画質

今の数字で書き直したコード（twigl の geekest にそのまま貼れます）

  • 一番よく化けるのは FS（折り返しの拡大率＝原典の abs(p+p) の 2）と FOLD（折り返しのずらし＝ −1）、それに J（折り回数）。まず「少しゆらす」で癖を掴むのが探しやすい。
  • SHARP を下げると線が太く霧のように、上げると髪の毛のように細くなる。GLOW は明るさの割り算なので大きいほど暗い。
  • SV は原典で smoothstep(-8,8,0)=0.5 と潰れていた回転軸Yの入力。動かすと軸が (X, 0〜AYM, Z) の間で振れる。
  • 出力は twigl の twigl.app「geekest」モードにそのまま貼れる1行。rotate2D / rotate3D / FC / r / t / o は組み込み。
